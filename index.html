Before you import

HTML is the ticket in.

FNF Play can unpack a browser build and remap its relative assets. It cannot convert a Windows, Mac, or Linux mod into HTML. If the build uses native APIs or a custom server, use its official web export or launch it directly.

quick guide

What counts as ready?

01

One HTML entry

We look for index.html, game.html, or main.html. Other files are okay, but one of those doors must exist.

02

Relative assets

Images, audio, video, CSS, and scripts with relative paths are remapped when possible. Dynamic filesystem calls are outside a browser sandbox.

03

Browser APIs

Keyboard input, canvas, WebAudio, and fullscreen are common. Native executables, desktop file APIs, and custom servers are not.

04

Keep a backup

Your imported files stay in memory for this tab. Save the original ZIP or folder; refreshes may require a re-import.
